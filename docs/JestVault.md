# JestVault

**Description**: A maximum-security digital vault serving up your daily dose of random jokes.

## Functionalities
- Fetches and displays a random joke with a sleek, neon-vault UI.
- Displays joke content along with relevant categories.
- Simulates an "unlocking" animation while fetching data.
- Allows users to cycle through jokes continuously.

## APIs Interacted With
Base URL: `https://api.freeapi.app/api/v1`
- `GET /public/randomjokes/joke/random` - Fetches a random joke object.

## Aesthetic Choices
Utilizes a vibrant neo-brutalist "Vault" theme. Deep, dark backgrounds (`bg-[#111827]`) are sharply contrasted with glowing amber and orange accents. It incorporates glassmorphic overlays and bouncing load animations to simulate "unlocking" a secure vault.
