# InkWell

**Description**: A classic, Shakespearean-styled archive for discovering and reading quotes.

## Functionalities
- Features a vintage aesthetic using sepia tones, parchment textures, and elegant typography.
- Displays a "Passage of the Moment" banner showing a completely random quote.
- Renders a masonry-style grid of quotes, complete with tags and authors.
- Includes a beautifully styled modal that shows detailed quote information when a card is clicked.
- Allows infinite-scrolling/pagination via a "Unfurl More Pages" button.

## APIs Interacted With
Base URL: `https://api.freeapi.app/api/v1`
- `GET /public/quotes` - Fetches a paginated list of quotes.
- `GET /public/quotes/quote/random` - Fetches a single random quote.

## Aesthetic Choices
Adopts a vintage, Shakespearean writer's desk motif. It relies heavily on warm sepia tones, deep mahogany (`#3e2723`), and aged-paper texture overlays. The typography uses classic serif fonts (Playfair Display, Times New Roman) and italics to evoke the feeling of reading from a classical literary archive.
