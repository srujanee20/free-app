# WhiskerView

**Description**: A playful, aesthetically pleasing application dedicated to discovering random cats and their breed information.

## Functionalities
- Fetches and displays a random cat picture.
- Shows detailed information about the cat's breed (if available), including origin, temperament, and lifespan.
- Renders animated rating bars for breed characteristics (e.g., affection level, energy level, intelligence).
- Provides external links to learn more about the specific breed (e.g., Wikipedia, Vetstreet).
- Includes a button to generate a new random cat.

## APIs Interacted With
Base URL: `https://api.freeapi.app/api/v1`
- `GET /public/cats/cat/random` - Fetches a random cat object, often including detailed breed metadata.

## Aesthetic Choices
Playful, vibrant, and energetic. The interface utilizes colorful gradient backgrounds, bouncy micro-animations, and rounded, friendly UI elements to perfectly match the fun, casual nature of browsing random cat pictures.
